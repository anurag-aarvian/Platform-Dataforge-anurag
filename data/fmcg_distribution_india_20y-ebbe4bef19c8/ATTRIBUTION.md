# Data sources and attribution

The demand, inventory, observation and notes data in this dataset are synthetic: generated by
Aarvian DataForge from a scenario spec and seed. The tables listed below are public real-world
data, identified by snapshot id and checksum: included as published, or used only to calibrate.
